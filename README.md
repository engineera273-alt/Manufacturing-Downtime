# Manufacturing Downtime

## Project Description

### English
The application aims to analyze production line productivity by tracking produced batches, products, production times, production line downtime, and the reasons behind downtime.

The project helps identify the main causes of production line downtime, analyze production performance, and provide insights that can contribute to improving productivity and overall production efficiency.

### العربية
يهدف التطبيق إلى تحليل إنتاجية خط الإنتاج (Production Line Productivity) من خلال متابعة الـ Batches المنتجة، والمنتجات، وأوقات الإنتاج، وأوقات توقف خط الإنتاج (Downtime)، بالإضافة إلى أسباب التوقف.

يساعد المشروع في تحديد الأسباب الرئيسية لتوقف خط الإنتاج، وتحليل أداء الإنتاج، واستخراج Insights تساعد على تحسين الإنتاجية ورفع كفاءة عملية الإنتاج.
